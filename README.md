# 🚀 My personal page 🚀

> URL: [willmendesneto.github.io](https://willmendesneto.github.io)

## 🧩 Tech Stack

- NVM
- React
- Styled-components
- GatsbyJS
- GraphQL

## 💻 Steps to run

- git clone https://github.com/willmendesneto/willmendesneto.github.io.git willmendesneto.github.io
- cd willmendesneto.github.io
- nvm use
- npm install
- npm start
- On browser [localhost:8000/](http://localhost:8000/)
