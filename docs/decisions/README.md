# Architecture decision records

One file per decision that changes a boundary, a dependency of note, or a convention. Numbered,
never deleted; superseded records point to their replacement. Integration choices count: a timeout
or retry value, a synchronous call that could be async, who owns a contract. Without the reason,
the next person can only accept the choice blindly or change it blindly.
